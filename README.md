# openai academy

my hands-on coursework from openai academy. each folder is a separate lab, built on starter material from openai and its course repositories.

| folder | what it is |
|---|---|
| [`codex-101-academy-lab`](./codex-101-academy-lab) | codex 101 lab: a next.js site, with an `AGENTS.md` file that gives coding agents instructions for the project. |
| [`codex-201-academy-lab`](./codex-201-academy-lab) | codex 201 lab: the same site with added about, contact and docs pages and shared navigation. |
| [`design-and-build-agentic-systems-guided-lab`](./design-and-build-agentic-systems-guided-lab) | design and build agentic systems lab: a customer-support agent in python with routing, tools and evals. |

## attribution
the starter code and course material come from openai and are mit licensed. each folder keeps its original `LICENSE`, and the agentic systems lab keeps its `ATTRIBUTION.md`. the data and tools in these labs are instructional examples only.

## setup
each lab has its own readme with setup steps. copy `.env.example` to `.env` and add your own api key. never commit `.env`.
